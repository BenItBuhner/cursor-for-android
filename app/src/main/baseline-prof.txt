# Baseline profile: the classes and methods ART compiles ahead of time, so a fresh install or update does not run the
# startup path interpreted until the device's idle+charging background dexopt. The app is sideloaded from GitHub
# Releases, so there are no Play cloud profiles to fall back on; androidx.profileinstaller installs this one from the
# APK (assets/dexopt/baseline.prof) on first launch.
#
# Hand-written wildcard rules in the human-readable profile format (H = hot, S = startup, P = post-startup; `L...;` lines
# are classes to preload). R8 rewrites them to the obfuscated names at build time. The Compose, lifecycle and activity
# AARs already ship their own profiles, which AGP merges in; the Compose rules below widen those to everything the app
# reaches through them. Keep the app rules to what cold start, the sidebar and the first chat open touch: a rule for
# the whole of com/cursorforandroid would also compile settings, the media viewer and the widgets.
